# Kompas

Een mobielvriendelijke, offline te gebruiken PWA voor dagelijkse check-ins en het vastleggen van opvallende focus-, rust- en vastloopmomenten. Inclusief inzichten, HTML-verslag en JSON-back-up.

## GitHub Pages

Ga naar **Settings → Pages → Build and deployment**, kies **Deploy from a branch**, branch **main**, map **/(root)** en klik op **Save**. Open daarna `https://yoeranmoreel.github.io/kompas/` en installeer de app via het browsermenu.

## Privacy en opslag

Check-ins worden **alleen lokaal in je browser** opgeslagen (`localStorage`), niet in GitHub. Een publieke repository is geen veilige opslag voor persoonlijke dagboekgegevens. Gebruik regelmatig **Mijn gegevens → Download back-up (JSON)**. Je kunt de back-up later importeren. Andere apparaten synchroniseren niet automatisch. Wis je browsergegevens niet zonder back-up.

De app is bedoeld voor zelfobservatie en stelt geen diagnose.
